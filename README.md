## 🌐 Overview / Tổng quan

**English:**  
`media2ascii` is a lightweight, zero-dependency, browser-based application designed to render both static images (PNG, JPG, WebP) and dynamic media (MP4, WebM, GIF, or live webcam stream) into retro ASCII art in real-time. Built purely with modern Vanilla JavaScript and HTML5 Canvas, it requires no backend servers or heavy frameworks.

**Tiếng Việt:**  
`media2ascii` là ứng dụng web siêu nhẹ, không phụ thuộc thư viện ngoài, giúp chuyển đổi cả hình ảnh tĩnh (PNG, JPG, WebP) lẫn video động (MP4, WebM, GIF, hoặc camera trực tiếp) thành nghệ thuật ASCII hoài cổ theo thời gian thực. Được phát triển hoàn toàn bằng Vanilla JavaScript và HTML5 Canvas, ứng dụng hoạt động 100% trên trình duyệt mà không cần máy chủ backend.

## 🛠️ How It Works / Nguyên lý hoạt động

### English
1. **Media Frame Capture:** Draws image or video frames onto an offscreen HTML5 `<canvas>`.
2. **Luminance Calculation:** Inspects RGBA pixel values and computes perceived brightness using standard luminance weighting:
   $$\text{Brightness} = 0.299 \cdot R + 0.587 \cdot G + 0.114 \cdot B$$
3. **Character Mapping:** Maps calculated brightness values to a customizable ASCII character density ramp:
   `" $@B%8&WM#*oahkbdpqwmZO0QLCJUYXzcvunxrft/\|()1{}[]?-_+~<>i!lI;:,"^\`'. "`
4. **Rendering:** Outputs character strings into a `<pre>` element or renders colored text back onto a visible display canvas.

### Tiếng Việt
1. **Trích xuất khung hình:** Bắt khung hình ảnh hoặc video đưa vào HTML5 `<canvas>` ẩn.
2. **Tính độ sáng điểm ảnh:** Đọc mảng dữ liệu RGBA và tính độ sáng thị giác (Luminance) theo công thức chuẩn:
   $$\text{Độ sáng} = 0.299 \cdot R + 0.587 \cdot G + 0.114 \cdot B$$
3. **Ánh xạ ký tự ASCII:** Chuyển mức độ sáng thành ký tự tương ứng trong chuỗi mật độ ASCII (từ tối nhất đến sáng nhất).
4. **Hiển thị:** Xuất văn bản ASCII ra thẻ `<pre>` hoặc vẽ lại ký tự có màu lên màn hình canvas.
